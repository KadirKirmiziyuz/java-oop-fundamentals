# Java OOP Learning & Practice

A hands-on Java repository documenting my learning journey through **Object-Oriented Programming (OOP)**, based on the Udemy course **"Java ile Nesne Merkezli Programlamaya Giriş"** by **Akın Kaldıroğlu**.

This repository contains course exercises, homework assignments, personal implementations, and refactored code developed throughout the learning process.

## 🎯 Learning Objectives

- **Object-Oriented Programming:** Understanding and applying Encapsulation, Abstraction, Inheritance, and Polymorphism.
- **Clean Code:** Improving code readability, maintainability, and following Java best practices.
- **Problem Solving:** Strengthening Java fundamentals through hands-on exercises.
- **Manual Testing:** Practicing code validation by executing methods with different inputs and checking their outputs.
- **Version Control:** Applying Git workflows and Conventional Commits to maintain a structured development history.
